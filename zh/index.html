iPhone

在你的 iPhone 上免费使用 Vesta。

App Store 中没有应用。从 Safari 将 Vesta 安装为网页应用，并连接到你 Windows 电脑上的 Vesta Agent（同一 Wi-Fi 或通过 Tailscale）。你可以使用聊天、语音和通知。iPhone 不支持手机控制。

1. 在电脑上打开 Vesta Agent > Settings > Phone connection，记下地址（或扫描二维码）。

2. 在 iPhone 上打开 Safari 并访问该地址（不在家时必须使用 https，例如通过 Tailscale）。

3. 点按“分享”按钮，然后点按 添加到主屏幕，再点按 添加.

4. 打开新图标并完成设置。聊天、语音和通知均可使用；智能体仍使用你电脑上的工具。

提示：同一地址也可在任意浏览器中作为书签使用。

常见问题

问题， 解答。

如何获取帮助或报告问题？

在 Telegram 上联系我们的支持机器人 @VestaAgentSupportBot。发送描述、截图或语音消息，你会收到一个工单号。回复会出现在同一个聊天中。

Vesta Agent 免费吗？

是的。Windows 和 Android 应用免费，免费的 iPhone 网页应用可连接到你电脑上的 Vesta。你使用自己的 AI 密钥，例如免费的 Gemini 或 OpenRouter 密钥，也可以用 Ollama 离线运行模型。

我的数据存储在哪里？

只在你自己的设备上：聊天、记忆、智能体、设置和加密的密钥。没有 Vesta 聊天服务器。可选的匿名使用统计（随机安装 ID、版本、系统、语言、国家/地区、设备类型和使用时长）可在设置中关闭。

在伊朗能用吗？

能。在设置中添加代理，例如 v2rayN 或 NekoBox 的本地端口，并选择哪些服务使用它。内置指南会展示每一步。

支持哪些 AI 模型？

Gemini、OpenAI、Anthropic、xAI (Grok)、OpenRouter、DeepSeek、Groq、Mistral、Together、NVIDIA NIM、任何兼容 OpenAI 的服务商，以及通过 Ollama 或 LM Studio 运行的本地模型。

会自动更新吗？

会。它在启动时静默检查，只有在有新版本时才弹出窗口，然后为你下载、校验并安装。

智能体工作时我还能继续聊天吗？

可以。从 1.7 开始，长任务在其聊天的后台运行。询问进度、添加或修改指示，或取消任务，工作都不会停止。

Vesta Agent 是谁开发的？

Persian Studio，由 SOBi 和 Mahan 创立。

为什么 Windows 显示蓝色警告？

安装程序尚未使用付费证书签名。点击 More info，然后点击 Run anyway。

隐私

你的数据 从不 离开家。

  • 没有 Vesta 聊天服务器，也没有存放你对话的在线数据库。聊天、记忆和设置都保存在你的设备上。可选的匿名使用统计（版本、系统、语言、国家/地区、设备类型和使用时长）可以关闭，关闭后不发送任何内容。
  • 偶尔出现的赞助卡片来自签名订阅源，绝不会看到你的聊天。轻点一下即可将任意卡片隐藏 7 天。
  • API 密钥在本地加密。密码、密钥和银行卡信息绝不会保存到记忆中。
  • 只有你发送的消息会发往你添加了密钥的 AI 服务商。使用 Ollama 时，什么都不会离开。
  • 麦克风或屏幕共享开启时，始终显示可见的指示标志。
