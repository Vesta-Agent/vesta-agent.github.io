Vesta Agent › Features

Capabilities

Everything an assistant should do.

One app, powerful agents, and no servers of ours in between.

01

Keeps working while you chat

Long tasks run in the background with a live status card. Keep chatting, ask how it is going, change the plan or cancel it, and the task carries on.

02

Phone control

The agent taps, types and navigates on Android, even without a computer.

03

Voice calls

Talk naturally and hear spoken replies. Share your screen mid-call and ask what is wrong.

04

Screen vision

With your permission the agent sees your screen, explains it and helps you fix it.

05

Multi-agent group chat

Put specialised agents in one room and let them split the work.

06

Memory stored locally

Smart memory that lives only on your device. View, edit or wipe it at any time.

07

Telegram

Connect your own bot or personal account and schedule messages.

08

Multi-key failover

Add several API keys per agent. When one runs out, the next one continues the same task.

09

Proxy for Iran

Real HTTP and SOCKS5 proxy per service, with a built-in step-by-step guide.

10

Offline mode

Run entirely on your computer with Ollama. Nothing leaves the machine.

11

Privacy first

No accounts and no cloud database. Keys are encrypted on your device.

12

Floating island

A small pill that stays on top: progress, approvals and quick chat from anywhere.

13

15 themes

Midnight, Aurora, Ocean, AMOLED black, Paper and more, applied with a smooth reveal. Each agent keeps its own shape and color.

14

Files from agents

Agents create PDF, Word, Excel, ZIP and media, with previews and a safety warning before programs.

15

NVIDIA NIM and more models

Gemini, OpenAI, Anthropic, xAI, OpenRouter, DeepSeek, Groq, Mistral, NVIDIA NIM and local models, with a searchable model list.

16

Reminders that fire

Scheduled tasks and reminders run even when the app is closed, on Windows and Android.

17

10 languages

English by default. Switch any time and the whole app updates at once, including Persian and Arabic right-to-left.

18

Builds apps for you

On Windows the agent can write a small program and package it as an .exe, an Android .apk (with the Android SDK installed) or an installable web app, icon included.

19

A calm, modern design

Glass surfaces, gentle motion and sounds, an animated lock screen and update window, and a Reduce animations mode for older PCs and phones.
